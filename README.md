# 🔥 Habit Tracker Pro

> **Build positive daily habits, track streaks, and measure your consistency with a sleek, responsive web application.**

---

## ✨ Key Features

- 📊 **Real-Time Habit Statistics**
  - Instant dashboard cards displaying **Total Habits**, **Done Today**, **Best Streak**, and **Completion Rate %**.

- 🎯 **Categorized Habit Management**
  - Add customized daily habits tagged across categories:
    - 💪 **Health & Fitness**
    - ⚡ **Productivity**
    - 🧠 **Mindset & Learning**
    - 🌿 **Lifestyle**

- 🔥 **Streak Analytics & Check-Offs**
  - Interactive daily check-off toggle with automatic streak incrementing and flame animations.
  - Keeps track of current consecutive streaks and personal best streak record.

- 🔍 **Filter & Quick Actions**
  - Filter habits by status: **All Habits**, **Active**, or **Completed**.
  - One-click **Reset Today's Checks** button to start a fresh daily routine.

- 💾 **100% Client-Side LocalStorage Sync**
  - Persists all habits and completion history locally in your browser with zero data latency.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3 (CSS Variables, Flexbox/Grid)
- **Fonts**: Google Fonts (Inter & Outfit)
- **Storage**: Web Storage API (LocalStorage)

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Omkar4812x/Habit-Tracker.git
   cd Habit-Tracker
   ```

2. **Launch Application**:
   Simply open `index.html` in any modern web browser or serve via Live Server.
